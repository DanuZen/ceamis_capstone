# Cakupan Proyek & Deliverables

## Scope

- Aplikasi web berbasis browser untuk Gen-Z Indonesia
- Fitur: autentikasi, pencatatan transaksi, dashboard AI, gamifikasi, manajemen utang-piutang, notifikasi
- Tidak mencakup: mobile native, integrasi rekening bank, sistem pembayaran, data finansial real-time

## Deliverables

- UI interaktif (Vite + Tailwind CSS)
- RESTful API (Express.js)
- AI Service (FastAPI, TensorFlow)
- Digital Ledger & Dashboard Analitik
- Fitur gamifikasi & notifikasi sarkas
- Dokumentasi lengkap & laporan teknis
