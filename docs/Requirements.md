# Functional & Non-Functional Requirements

## Functional

- Autentikasi (guest/user)
- Pencatatan transaksi & digital ledger
- Dashboard AI + XAI
- Gamifikasi (streak, badge, leaderboard)
- Gen-Z Warning System (notifikasi sarkas)
- AI Chatbot & edukasi adaptif

## Non-Functional

- Keamanan data (enkripsi, JWT)
- Responsivitas UI (Vite, Tailwind)
- Skalabilitas API (Express modular)
- Performa AI (akurat, explainable)
- Dokumentasi & maintainability
