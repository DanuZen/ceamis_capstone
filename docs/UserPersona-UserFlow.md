# User Persona & User Flow

## User Persona

- Mahasiswa (18–23): Suka challenge, impulsif, ingin belajar finansial
- Fresh Graduate (22–25): Mulai mandiri, suka insight instan, tech-savvy

## User Flow

1. Masuk (guest/user)
2. Catat transaksi
3. Dapat insight AI & XAI
4. Notifikasi Gen-Z Warning
5. Chatbot & edukasi
6. Reward gamifikasi
