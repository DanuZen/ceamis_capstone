# Cakupan Proyek & Deliverables (CEAMIS 1.0)

> [!NOTE]
> **Catatan Evolusi ke CEAMIS 2.0:**  
> Ruang lingkup di bawah merupakan batasan pada fase **CEAMIS 1.0 (Web MVP)**. Pada **CEAMIS 2.0**, cakupan diperluas mencakup **Aplikasi Mobile (Flutter)** dan **Smart OCR Scan Struk**. Rincian ruang lingkup terbaru dapat dibaca pada [PRD.md](PRD.md) dan [PANDUAN_FITUR_BARU_MOBILE_OCR.md](PANDUAN_FITUR_BARU_MOBILE_OCR.md).

## Scope (Versi 1.0)

- Aplikasi web berbasis browser untuk Gen-Z Indonesia
- Fitur: autentikasi, pencatatan transaksi, dashboard AI, gamifikasi, manajemen utang-piutang, notifikasi
- Tidak mencakup: mobile native, integrasi rekening bank, sistem pembayaran, data finansial real-time

## Deliverables (Versi 1.0)

- UI interaktif (Next.js / Tailwind CSS)
- RESTful API (NestJS Core Backend)
- AI Service (FastAPI, TensorFlow)
- Digital Ledger & Dashboard Analitik
- Fitur gamifikasi & notifikasi sarkas
- Dokumentasi lengkap & laporan teknis
